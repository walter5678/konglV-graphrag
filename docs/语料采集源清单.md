## 二、按维度补充源（中/低优先）

**国家法规替代源**
- 司法部 国家行政法规库2.0 `moj.gov.cn/sfbsearch/` —— 行政法规历次修订**版本对照**，弥补 flk 缺口（免费）

**民航局规范性文件聚合**
- 低空经济网（科促会）`laeb-cipast.com` —— 国家/地方政策**时间线**逐条带原文链接，分页 `p=` 可批量（二次转载，需回源校验）
- 中国民用航空网 `ccaonline.cn/tongyong/zefgtyhk` —— 政策法规栏目免费读，但**WebFetch 返回 403 有反爬**，需带浏览器指纹爬虫

**标准文字版**
- 地方标准平台 `dbba.sacinfo.org.cn` —— 各省 DB 系列地方标准，支持 PDF 下载
- 学兔兔 `bzfxw.com` —— 非官方，每日限 2 次下载，仅作缺件补充

**司法案例（整体降级，见下方结论3）**
- 人民法院案例库 `rmfyalk.court.gov.cn` —— 约 3927 篇指导/参考案例，多字段检索；无专门无人机专题，需关键词全文检索；匿名访问边界待实测
- 地方司法局"以案释法"专栏（如深圳 `sf.sz.gov.cn`）—— 零散权威，定向补充
- ⚠ 中国裁判文书网 `wenshu.court.gov.cn` —— 2023-11 起转法院内网，公开量断崖下滑，**不建议做主力源**
- ⚠ 威科先行 `wkinfo.com.cn` —— 付费商业库，仅机构订阅，不可批量采集

**官方解读/白皮书/政策背景**
- AOPA《低空经济重点政策制度汇编(2025)》—— 分层政策清单，可作**目录索引反查**官方原文
- 新华网/中新网低空经济专栏、低空界研究报告栏目 —— 白皮书/解读语料（权威性弱于一手法规，作"解读语料"用）

## 三、关键结论

1. **最有价值新发现 = 低空界 `dikongjie.com` 地方法规库**：全国省市级地方条例已全文聚合，建议作地方法规维度第一采集源（正文回源官网核验）。
2. **`hbba` + `std.samr/hb` 组合解决 MH 标准文字版痛点**：实测确认是在线文字版而非扫描件，优先开发（可避免 GB42590 那种扫描件 OCR 的成本）。
3. **司法案例维度整体降级**：裁判文书网公开量萎缩，转向"人民法院案例库定向关键词检索 + 地方司法局普法专栏"的小规模精选，付费库不投入。
4. **国务院政策库 / 部分站点为 JS 渲染或有反爬**，需 Playwright 或逆向接口，不能用简单 requests。
5. **npc.gov.cn 静态页**是新版《民用航空法》等法律全文的可靠免费直连来源。
