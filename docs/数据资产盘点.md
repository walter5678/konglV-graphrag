## 五、盘点结论与整理建议

1. **去重主键统一**：以「法规名 + 文号」为主键，跨 A/B/C 三区去重（尤其 pkulaw 的 20 篇与 B 区 04/05 存在交叉，如"驾驶员管理规定""轻小无人机运行规定"）。北大法宝 `法宝引证码 CLI.x` 作为 pkulaw 内部唯一 ID。
2. **时效性一等公民**：入库即打 `时效性/施行日期`，检索默认过滤废止件。已知须处理的时效关系：
   - 2017《实名制登记管理规定》(AP-45-AA-2017-03) → 被 **GB 46761-2025**(2026-05-01) 取代；
   - 民航法 **2026-07-01 新版** 取代 2021 修正版；
   - AC-92-AA-2024-02(中型适航试行) 或被 **AC-21-AA-2026-44**(限用类) 覆盖，待核。
3. **优先级**：P0 先解析 B 区 62 份精选原文（HTML 易、PDF 需 OCR/整理）→ 与 A 区 651 条合并；C 区海量语料按"无人机/低空"专题增量补入并去重。
4. **案例/解读单列**：07 目录与 pkulaw 司法案例包，建 `案例`→`法条` 援引边，不混入法条 chunk。
