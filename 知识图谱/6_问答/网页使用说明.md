## 一、启动网页（三步）

> 需要联网。首次换机部署另见文末「换机注意」。

### 第 1 步：启动 Neo4j 图数据库

新开一个 PowerShell 窗口，运行：

```powershell
D:\Neo4j\neo4j-community\neo4j-community-2026.06.0\bin\neo4j.bat console
```

看到 `Started.` 即成功。**这个窗口保持开着别关**（关掉图数据库就停了，图谱扩展功能会失效）。

### 第 2 步：设置密钥（同一个新窗口里）

```powershell
$env:SILICONFLOW_API_KEY = "sk-硅基流动的key"   # 检索用（向量嵌入 + 精排）
$env:LLM_API_KEY         = "智谱开放平台的key"   # 生成答案用（免费 GLM-4-Flash）
```

### 第 3 步：启动网页服务

```powershell
cd D:\schoolwork\competition\低空经济无人机法律智能问答比赛\知识图谱\6_问答
python server.py
```

出现 `▶ 无人机法律问答服务：http://127.0.0.1:8000` 后，用浏览器打开 **http://127.0.0.1:8000** 即可。

## 二、页面怎么用

1. **提问**：在底部输入框输入问题（支持口语，如"黑飞怎么处罚""小飞机要登记吗"），点 ➤ 或回车发送。
2. **看答案**：答案逐字流式生成，关键结论会标注《法规名》和条号。
3. **看依据**：答案下方可展开引用来源——
   - **主命中条文**：检索直接命中的法律条文，带效力状态标签（现行有效 / 已废止等）。
   - **关联条款**：知识图谱多跳扩展补充的相关条文，附溯源说明。
   - 点开每条可看条文全文。
4. **示例问题**：页面上方有示例，点一下即可直接提问，适合快速体验。

### 顶部四个开关

| 开关 | 作用 | 建议 |
|---|---|---|
| **模式** | hybrid（向量+关键词）/ dense（纯向量）/ sparse（纯关键词，免检索 key） | 默认 hybrid |
| **精排 rerank** | 对候选做二次精排，提升相关性 | 默认开 |
| **图谱扩展** | 用知识图谱补充关联条款 | 默认开 |
| **仅现行有效** | 过滤掉已废止 / 未生效条文 | **建议常开**（法律问答须用现行版） |

## 三、常见问题

- **答案区提示"检索失败，需 SILICONFLOW_API_KEY"**：第 2 步的检索密钥没设或无余额。临时办法：把顶部**模式切到 `sparse`**（纯关键词检索，不需要该 key，仍能出答案）。
- **提示"生成端未就绪"**：`LLM_API_KEY`（智谱 key）没设，重做第 2 步。
- **没有"关联条款"/ 图扩展报警**：Neo4j 没起或已关闭，回到第 1 步。不影响主答案，只是少了图谱扩展。
- **想让别人从局域网访问**：改用 `python server.py --host 0.0.0.0 --port 8080`，别人访问 `http://你的IP:8080`。
- **健康自检**：浏览器打开 http://127.0.0.1:8000/api/health 可看各依赖（检索 key / 生成 key / Neo4j）是否就绪。

> 答案由 AI 依据检索到的法规条文生成，仅供参考，不构成法律意见。

## 换机注意（首次部署才需要）

1. 装依赖：`pip install fastapi uvicorn openai "chromadb==0.4.24" jieba rank_bm25 neo4j "posthog==2.5.0"`
2. **向量库**：Chroma 库在 `C:\Users\zy133\drone_law_chroma`（中文路径坑挪出的），换机需拷贝过去，并设 `$env:DRONE_CHROMA_DIR` 指向它。
3. **Neo4j**：换机需装 Neo4j 并导入图谱 `知识图谱\3_建图\out\neo4j_import.cypher`（用 cypher-shell 的 `-f` 参数，不能用管道）。
